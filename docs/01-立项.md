# 01 · 立项

## 背景与动机

- 用户自建 Proxmox VE（PVE）宿主机，日常需要远程管理
- 家庭网络无公网 IPv4 端口转发（不信任直接暴露公网）
- PVE WebUI 没有移动端适配，手机浏览器操作不便
- 飞牛 fnOS 提供 FN Connect 穿透服务（无公网 IP 也能访问，自动选路：直连 / P2P / 中继）
- 机会：飞牛用户群体庞大，其中不乏 PVE 自建用户，**需要一个开箱即用的「PVE 远程管理」应用**

## 产品定位

> 基于飞牛 OS 的 Proxmox VE 远程管理应用：移动端原生 API 体验，PC 端透传原版 WebUI，通过 FN Connect 穿透实现无公网 IP 也能远程管理。

一句话：**把 PVE 装进飞牛应用商店，一个链接远程管理。**

## 目标用户

- 飞牛 fnOS 用户中自建 PVE 的用户（个人 / 家庭 / 小型工作室）
- **大多数没有公网 IP**，依赖 FN Connect 穿透
- 移动端（手机/平板）与 PC 双端访问

## 核心价值

1. **无公网 IP 远程管理**：FN Connect 穿透，一个链接即达
2. **移动端可用**：原生 API 界面，替代手机浏览器操作原版 WebUI 的痛苦
3. **PC 端零损失**：原版 WebUI 完整透传，桌面用户无迁移成本
4. **低门槛**：应用商店一键安装 + 配置向导，小白也能接 PVE

## 边界（非目标，第一版明确不做）

- ❌ 不做完整 PVE 管理客户端（备份/网络/存储全量管理）
- ❌ 不做多平台独立客户端（不碰 iOS/桌面 App，只做移动端 Web）
- ❌ 不内置反向代理（依赖商店反代容器）
- ❌ 不做 PVE 替代（管理入口，不碰虚拟机数据面）

## 开源协议

**MIT** — 理由：
- 独立 API 客户端，不包含 PVE 代码，无 AGPL 传染义务
- 最宽松，商用/二次开发无顾虑，飞牛社区集成友好
- 利于吸引社区贡献者

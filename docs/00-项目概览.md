# PVE 管家（pve-pilot）

> 基于飞牛 OS（fnOS）的 Proxmox VE 远程管理应用。
> 移动端提供原生 API 体验，PC 端透传原版 WebUI，通过 FN Connect 穿透实现无公网 IP 也能远程管理。

- **中文名**：PVE 管家
- **英文名 / GitHub 仓库名**：`pve-pilot`
- **开源协议**：MIT
- **发布渠道**：飞牛 fnOS 应用商店（面向所有飞牛用户）

## 里程碑（规划）

1. **V1（MVP）**：PC 端通过 FN Connect 链接访问原版 PVE WebUI（内置反代引擎 + 配置向导 + 商店打包）
2. **V2**：移动端界面（对接 PVE API：节点状态 / VM 列表 / 电源操作）+ noVNC 控制台
3. **V3+**：快照/备份、多节点、通知推送等

# 03 · 调研：fnOS 应用生态

> 调研日期：2026-08-02。来源：FNOSP GitHub、conversun/fnos-apps、飞牛帮助中心、飞牛社区。

## 1. 应用打包格式（.fpk）

```
.fpk = tar.gz，包含：
├── manifest          # 应用清单（键值对）
├── *.sc              # 服务/端口转发声明（INI 风格）
├── app.tgz           # 应用本体（非 Docker 应用）
├── cmd/              # 安装/启停脚本（service-setup，shared + app 覆盖）
├── config/           # 配置（privilege / resource）
├── var/              # 数据种子文件（同步到 TRIM_PKGVAR）
├── wizard/           # 安装向导
├── ui/               # UI 配置（ui/config = 安装表单）
├── ICON.PNG          # 图标（64 与 256）
└── ui/images/256.png # 由 ICON_256.PNG 生成
```

### manifest 关键字段

```
appname = <应用标识>
version = <版本>
display_name = <显示名>
service_port = <服务端口>
checkport = <bool>
platform = x86 | arm
maintainer / maintainer_url
distributor / distributor_url
desktop_uidir = ui
desktop_applaunchname = <应用>.Application
desc = <中文描述>
source = thirdparty
checksum = <md5(app.tgz)>
```

### .sc 端口转发声明

```
[AppName]
title="AppName"
desc="AppName Service"
port_forward="yes"
src.ports="81/tcp,880/tcp,4443/tcp"
dst.ports="81/tcp,880/tcp,4443/tcp"
```

> `port_forward="yes"` 与 FN Connect 穿透直接相关——应用声明端口后可被穿透访问。

### Docker 应用

- 目录：`fnos/docker/docker-compose.yaml`
- 模板变量：`${TRIM_SERVICE_PORT}`（服务端口）、`${TRIM_PKGVAR}`（数据目录）、`${DOCKER_MIRROR}`（镜像加速）、`${VERSION}`
- 示例（Nginx Proxy Manager）：镜像 `jc21/nginx-proxy-manager`，端口 880/81/4443，数据卷挂载 `${TRIM_PKGVAR}/data`

## 2. 反代应用（依赖候选）

商店现有：
- **nginx**（原生二进制打包）
- **nginx-ui**
- **Nginx Proxy Manager**（Docker 应用，图形化管理）

→ 「PVE 管家依赖商店反代容器」成立。**注意：manifest 无 depends 字段，fnOS 不支持显式应用依赖**——需应用内检测 + 向导引导安装。

## 3. FN Connect 穿透

- 机制：注册飞牛账号 → 创建唯一 FN ID → 获得 `https://fnos.net/<FNID>` 子域名 + 自动 SSL 证书
- 选路策略：公网 IP 直连（可配置）→ P2P（IPv6，安全无限速）→ 中继转发（**限速**，有流量成本）
- 应用侧：通过 `.sc` 声明端口，FN Connect 可转发到应用端口

## 4. 官方开发者平台（FNOSP）

GitHub 组织 `FNOSP` 关键仓库：
| 仓库 | 用途 |
|:--|:--|
| `fnmake` / `fnpack` | 应用打包工具（fnpack：快速创建项目结构 + 打包 .fpk） |
| `fnnas-api` | 飞牛 NAS 网页 API |
| `fnosAppCenterCgiCollection` | 应用中心通用网关接口（CGI）集合 |
| `FnDepot` | 应用源仓库 |
| `fnos-mcp-server` | 飞牛系统 MCP 服务 |
| `App.Docker.*` / `App.Bin.*` | 官方应用示例（可作模板） |

## 5. 发布渠道

1. **官方应用商店**：飞牛官方上架（社区有开发者申请渠道，需审核）
2. **第三方商店**：conversun/fnos-apps（GitHub 仓库，CI 自动打包 .fpk，PR 提交）
